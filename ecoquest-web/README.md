# EcoQuest 🌱

> A world-class, premium gamified environmental education platform that transforms sustainability learning into real-world action.

Designed with a clean, modern startup aesthetic inspired by Apple, Linear, Stripe, Vercel, and Duolingo. Features an emerald green eco-friendly color palette, glassmorphism, background particle animations, AI verification simulator, live leaderboards, and an interactive school impact calculator.

---

## ✨ Features

- 🌿 **Sticky Glass Navigation**: Blurred glass header transitioning on scroll with responsive mobile drawer menu.
- ⚡ **Split-Screen Hero**: Animated text gradients, social proof, and interactive 3D visual card composition (+100 XP, AI Verified, Leaderboard rank badges).
- 🏆 **Live Leaderboards**: Inter-class, inter-grade, and school vs. school rankings with gold/silver/bronze podium displays.
- 🤖 **AI Photo Verification Simulator**: Interactive demo scanning student eco-challenge photos in real time with confidence scores and confetti celebrations.
- 📊 **Interactive Impact Calculator**: Live slider widget calculating yearly plastic waste saved, CO2 reduced, and trees grown per school.
- 🛡️ **Contact & Onboarding Modals**: Role-based signup for Students, Educators, and School Administrators.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism CSS System
- **Icons**: Lucide React
- **Animations**: Canvas Confetti & Custom Keyframes

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Local Setup

```bash
# Clone the repository
git clone https://github.com/varshanalpha/EcoQuest.git
cd EcoQuest

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5176` (or `http://localhost:5173`) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
